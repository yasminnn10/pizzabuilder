# Pizza Builder Project (Assignment 1)

This project is an implementation of the Builder design pattern in Java.

## Structure:
* **Pizza** - Immutable pizza object.
* **PizzaBuilder** - Interface defining construction steps.
* **PizzaObjectBuilder** - Creates a Pizza object and validates required ingredients.
* **PizzaReceiptBuilder** - Creates a text receipt instead of an object.
* **PizzaDirector** - Stores ready recipes (Margarita, Pepperoni, Four Cheese).
* **Main** - Runs the demo code.
